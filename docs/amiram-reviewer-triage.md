עותק טקסט: `docs/amiram-reviewer-feedback.txt`

## מה זה בעצם?

רוב ההערות הן על **תוכן השיעורים** (שקופיות markdown), לא על באגי תשלום/auth.  
תוקנו גם בקוד: פיצול fence, אריזת `(A)–(D)`, strip של `<details>`/checkbox, קיטוע קטעי קריאה בגבול פסקה, LTR לריקים באנגלית, side-by-side לקריאה, **נגן שמיעה + shortcode**.

## דפוסים חוזרים

| דפוס | סטטוס |
|------|--------|
| שאלה / אפשרויות / הסבר נחתכים | ✅ תוכן + packer MC + WHOLE_SUBSECTION |
| `<details>` גולמי | ✅ strip + ניקוי תוכן |
| תשובות בלי השאלה | ✅ חזרה לשאלה / חבילות |
| "עקרונות זהב" / ניסוח AI | ✅ טיפים + טון טבעי |
| לשון זכר | ✅ סבב רבים ב־1–8 (טיפים/פתיחות) |
| מבחני שמיעה בלי אודיו | ⏳ תשתית נגן+מניפסט מוכנה; **חסרים קבצי MP3** |
| קריאה בלי קטע ליד שאלות | ✅ Adaptive + PracticeSet + pill לקטע ארוך |
| checkbox / blanks ב-RTL | ✅ strip + isolateFillInBlanks |

## נשאר (הקלטה / העלאה)

1. לשים 5 קבצי MP3 ב־`public/amirant-listening/` (שמות ב־README שם)  
2. לעדכן `src` ב־`src/lib/amirant-course/listening-audio/manifest.ts`  
3. (אופציונלי) שאלוני אבחון ביחידה 1 בלשון רבים  

**תשתית שמיעה:** `{{audio:id|title}}` → `AmirantAudioPlayer` (מצב מבחן / תרגול + placeholder).
