## מה זה בעצם?

רוב ההערות הן על **תוכן השיעורים** (שקופיות markdown), לא על באגי תשלום/auth.  
חלק כבר תוקן בקוד (פיצול fence, strip של `<details>`, שמירת שאלה+תשובה יחד עד 2400 תווים).

## דפוסים חוזרים (כל הפרקים)

| דפוס | מה לבודקת | סטטוס |
|------|-----------|--------|
| שאלה / אפשרויות / הסבר נחתכים בין שקופיות | מבלבל מאוד | ✅ שיפור בקוד + תוכן (חזרה לשאלה / חבילות) |
| `<details>` גולמי על המסך | באג תצוגה | ✅ strip ברינדור |
| תשובות בלי השאלה לידן | למידה חלשה | ✅ בעיקר ב־5–8 (חזרה לשאלה) |
| "עקרונות זהב" / ניסוח AI | טון | ✅ טיפים + ניסוח טבעי יותר בפרקים שעובדו |
| לשון זכר בכל הקורס | הערה אסטרטגית | ✅ סבב ב־5–8 + טיפים; לא כל הקורס היסטורי |
| מבחני שמיעה בלי אודיו | מוצר חסר | ⏳ הודעה כנה + לינקים חיצוניים; קבצי אודיו עדיין חסרים |
| קריאה בלי קטע ליד השאלות | UX | ✅ side-by-side ב־Adaptive + PracticeSet |
| ריבועי checkbox בכותרות | `- [ ]` ב-MD | ✅ strip + ניקוי סימולציות/כתיבה |

## סדר עבודה

1. ✅ מיפוי + שמירת המסמך בריפו  
2. ✅ תיקוני קוד שיטתיים (checkbox, side-by-side, microsection blockquotes)  
3. ✅ תוכן SC + rephrase + reading + reform + sim  
4. ⏳ אודיו לשמיעה — החלטת מוצר + העלאת קבצים/לינקים מובנים  
5. ⏳ (אופציונלי) סבב לשון רבים על יחידות 1–3 / אוצר מילים אם יישארו הערות  

עדכונים יסומנו כאן כשנסגרים.
