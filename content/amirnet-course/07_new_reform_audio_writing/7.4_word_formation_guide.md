# יחידה 7.4 - מדריך Word Formation 📝
## בניית מילים - הבנת שורשים, קידומות וסיומות

---

## 🎯 מה זה Word Formation?

זה חלק חדש במבחן AMIRNET לאחר הרפורמה. הוא בודק את יכולתך **לבנות מילה נכונה בהתאם להקשר דקדוקי**.

**דוגמה:**
```
The decision was completely _____ (expect).
Answer: unexpected
```

כאן צריך:
1. לזהות שזה תואר (adjective) - כי הוא אחרי "was"
2. לזהות שזה שלילי - "completely unexpected"
3. לבנות: un- + expect + -ed = unexpected

---

## 🧩 העקרונות הבסיסיים

### 1. **שורש המילה** (Root)
- הבסיס של המילה
- נושא את המשמעות הראשית
- דוגמה: **act** (פעולה) → act, action, active, react, reaction

### 2. **קידומת** (Prefix)
- מתווספת **לפני** השורש
- משנה את המשמעות
- דוגמה: **un-** + happy = unhappy (לא שמח)

### 3. **סיומת** (Suffix)
- מתווספת **אחרי** השורש
- לרוב משנה חלק דיבר
- דוגמה: act (v) + **-ion** = action (n)

---

## 📋 קידומות חשובות (Prefixes)

### קידומות של שלילה:
| קידומת | משמעות | דוגמה |
|---|---|---|
| **un-** | לא | un + happy = unhappy |
| **in-** | לא | in + active = inactive |
| **im-** | לא (לפני p, b, m) | im + possible = impossible |
| **il-** | לא (לפני l) | il + legal = illegal |
| **ir-** | לא (לפני r) | ir + regular = irregular |
| **dis-** | הפוך | dis + agree = disagree |
| **non-** | לא | non + sense = nonsense |
| **anti-** | נגד | anti + social = antisocial |
| **mis-** | לא נכון | mis + understand = misunderstand |

### קידומות של זמן ומקום:
| קידומת | משמעות | דוגמה |
|---|---|---|
| **pre-** | לפני | pre + pay = prepay |
| **post-** | אחרי | post + war = postwar |
| **re-** | שוב | re + do = redo |
| **sub-** | מתחת | sub + way = subway |
| **super-** | מעל | super + man = superman |
| **trans-** | מעבר | trans + port = transport |
| **inter-** | בין | inter + national = international |

### קידומות של מידה:
| קידומת | משמעות | דוגמה |
|---|---|---|
| **over-** | יותר מדי | over + work = overwork |
| **under-** | פחות מדי | under + estimate = underestimate |
| **multi-** | הרבה | multi + media = multimedia |
| **semi-** | חצי | semi + circle = semicircle |
| **ultra-** | מאוד | ultra + modern = ultramodern |

## 📋 סיומות חשובות (Suffixes)

### סיומות של **שם עצם** (Noun):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-tion / -sion** | פעולה | educate → education, decide → decision |
| **-ment** | מצב/פעולה | develop → development |
| **-ness** | איכות | happy → happiness |
| **-ity / -ty** | איכות | real → reality |
| **-er / -or** | אדם | teach → teacher |
| **-ist** | אדם עם מקצוע | art → artist |
| **-ism** | אידיאולוגיה | capital → capitalism |
| **-ship** | מצב/יחס | friend → friendship |
| **-hood** | מצב | child → childhood |
| **-dom** | מצב | free → freedom |
| **-ance / -ence** | איכות | import → importance |

### סיומות של **תואר** (Adjective):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-ful** | מלא ב- | beauty → beautiful |
| **-less** | ללא | hope → hopeless |
| **-able / -ible** | ניתן ל- | read → readable |
| **-al** | של / שייך ל- | nature → natural |
| **-ous** | מלא ב- | danger → dangerous |
| **-ive** | נוטה ל- | act → active |
| **-ic** | של / שייך ל- | hero → heroic |
| **-y** | מלא ב- | rain → rainy |
| **-ish** | כמו | child → childish |
| **-ed** | שעבר פעולה | interest → interested |
| **-ing** | שעושה פעולה | interest → interesting |

### סיומות של **פועל** (Verb):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-ize / -ise** | להפוך ל- | modern → modernize |
| **-ate** | לעשות | create, generate |
| **-en** | להפוך ל- | short → shorten |
| **-ify** | לעשות | simple → simplify |

### סיומות של **תואר הפועל** (Adverb):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-ly** | באופן | quick → quickly |

## 🎯 אסטרטגיות לפתרון שאלות

### אסטרטגיה #1: **זהה את חלק הדיבר הנדרש**

שאל את עצמך: **איזו מילה חסרה?**
- **פועל (verb)?** - אם אין פועל במשפט
- **שם עצם (noun)?** - אחרי `the`, `a`, `an`, או כנושא/מושא
- **תואר (adjective)?** - לפני שם עצם או אחרי to-be
- **תואר הפועל (adverb)?** - מתאר פועל או תואר

### אסטרטגיה #2: **נתח את ההקשר**

קרא את המשפט המלא!
- **שלילי?** → השתמש בקידומת שלילה (un-, in-, im-, il-, ir-)
- **עבר?** → הוסף -ed
- **אקטיבי?** → הוסף -ing
- **אדם?** → הוסף -er, -or, -ist

### אסטרטגיה #3: **זהה מילה דומה שאתה מכיר**

אם אתה לא מכיר את המילה הספציפית, חשוב על מילים דומות:
- `educate` → לא בטוח? תחשוב על `education`, `educational`, `educator`
- כולן באותה משפחה!

### אסטרטגיה #4: **בדוק את הסיומת של המילה במילה המקור**

| מה יש לך | מה אתה רוצה | איך? |
|---|---|---|
| education (n) | to educate (v) | הורד -ion |
| successful (adj) | success (n) | הורד -ful |
| quickly (adv) | quick (adj) | הורד -ly |

## 📊 טבלת המרה מהירה

### מילה אחת → כל הצורות:

#### דוגמה: **educate**
| חלק דיבר | מילה | דוגמה במשפט |
|---|---|---|
| פועל (verb) | educate | She educates children. |
| שם עצם (noun) | education | Education is important. |
| שם עצם (person) | educator | He is a skilled educator. |
| תואר (adjective) | educational | This is an educational video. |
| תואר שלילי | uneducated | Uneducated people struggle. |

#### דוגמה: **succeed**
| חלק דיבר | מילה | דוגמה במשפט |
|---|---|---|
| פועל | succeed | She succeeded in her goal. |
| שם עצם | success | His success was incredible. |
| תואר | successful | A successful businessman. |
| תואר הפועל | successfully | She completed it successfully. |
| תואר שלילי | unsuccessful | The attempt was unsuccessful. |

#### דוגמה: **decide**
| חלק דיבר | מילה | דוגמה במשפט |
|---|---|---|
| פועל | decide | I will decide tomorrow. |
| שם עצם | decision | Her decision was clear. |
| תואר | decisive | A decisive victory. |
| תואר הפועל | decisively | He acted decisively. |
| תואר שלילי | indecisive | An indecisive leader. |

## ⚠️ מלכודות נפוצות

### מלכודת 1: **בחירת הקידומת השלילית הלא נכונה**

**כלל:**
- לפני **L** → **il-** (legal → illegal)
- לפני **R** → **ir-** (regular → irregular)
- לפני **P, B, M** → **im-** (possible → impossible)
- אחרים → **in-** (active → inactive)
- הרבה פעמים → **un-** עובד עם כל סוג של מילה

### מלכודת 2: **בחירת הסיומת הלא נכונה**

**דוגמה:**
- success → successful (לא "successfull" או "succesful"!)
- necessary → necessarily (לא "necessaryly"!)

### מלכודת 3: **התעלמות מהקשר השלמותי**

**דוגמה:**
"The decision was _____ (expect)."
- ❌ expected (חיובי - לא מתאים להקשר)
- ✅ unexpected (שלילי - ההחלטה הייתה בלתי צפויה)

רק אם תקרא את המשפט המלא תבין שצריך שלילה.

### מלכודת 4: **שכחת הכפלה כפולה של אותיות**

- happy → happiness (לא "hapiness")
- beautiful → beautiful (2 L!)

## 📝 טיפים לשימוש בזמן מבחן

### 💡 טיפ 1: **קרא את כל המשפט תחילה**

אל תמלא את החסר מיד - קרא את המשפט, הבן את המשמעות.

### 💡 טיפ 2: **זהה את חלק הדיבר**

סמן בעיפרון:
- לפני שם עצם → צריך תואר
- אחרי to-be → צריך תואר
- כנושא/מושא → שם עצם
- אחרי פועל → תואר הפועל

### 💡 טיפ 3: **שאל: חיובי או שלילי?**

מילים כמו `not`, `without`, `un-`, `lack of` מאותתות על שלילה.

### 💡 טיפ 4: **בדוק תחבירית**

האם הצורה שלך מתיישבת עם המשפט?
- **Singular/Plural?**
- **Past/Present/Future?**

## 🎓 דוגמאות לתרגול מהיר

**קריאה פעילה:** ספר את חלק הדיבר של המילה הנכונה.

### דוגמה 1:
"The ancient civilization had many _____ (achieve)."

- לפני _____ יש "many" (הרבה) → צריך שם עצם ברבים
- **תשובה: achievements** (הישגים)

### דוגמה 2:
"His response was totally _____ (expect)."

- אחרי to-be → תואר
- "totally" מאותת על שלילה או הפלגה
- **תשובה: unexpected** (לא צפוי)

### דוגמה 3:
"She spoke _____ (clear) during the presentation."

- מתאר פועל (spoke) → תואר הפועל
- **תשובה: clearly** (בבירור)

### דוגמה 4:
"The project's _____ (succeed) was due to hard work."

- אחרי "project's" → שם עצם
- **תשובה: success** (הצלחה)

### דוגמה 5:
"It was _____ (possible) to finish on time."

- אחרי to-be → תואר
- ההקשר שלילי (was possible אבל לא הצליחו)
- **תשובה: impossible** (בלתי אפשרי)
