# יחידה 7.4 - מדריך Word Formation 📝
## בניית מילים - הבנת שורשים, קידומות וסיומות

---

## 🎯 מה זה Word Formation?

זה חלק חדש במבחן AMIRNET לאחר הרפורמה. הוא בודק את היכולת **לבנות מילה נכונה בהתאם להקשר דקדוקי**.

**דוגמה (אותו שורש → צורות שונות):**
```
The _____ of the new bridge took three years. (construct)
Answer: construction
```

כאן:
1. אחרי `The` ולפני `of` → צריך **שם עצם**
2. בונים: construct + **-ion** = construction

הדוגמה מראה את הרעיון: **אותו שורש** (construct) מוטה לצורות שונות – construct / construction / constructive / reconstruct – והמבחן בודק איזו צורה מתאימה למשפט.

---

## 📚 תזכורת: חלקי דיבר בעברית (לפני שמתחילים)

במדריך הזה חוזרים שוב ושוב על "חלק דיבר". הנה תרגום קצר לדוברי עברית:

| באנגלית | בעברית | מה זה עושה | דוגמה |
|---|---|---|---|
| **Noun** | שם עצם | אדם / חפץ / רעיון | decision, beauty, success |
| **Verb** | פועל | פעולה | decide, beautify, succeed |
| **Adjective** | תואר (שם תואר) | מתאר שם עצם | decisive, beautiful, successful |
| **Adverb** | תואר הפועל | מתאר פועל / תואר / משפט שלם | decisively, beautifully, successfully |
| **Gerund / -ing noun** | שם פעולה | פעולה כשם עצם (לרוב עם -ing) | swimming, building, learning |

**כלל אצבע:** שם עצם = *מה?* · פועל = *מה עושים?* · תואר = *איזה?* · תואר הפועל = *איך?*

## מה נלמד בפרק? (תוכן עניינים)

1. שורש · קידומת · סיומת – העקרונות
2. קידומות חשובות (כולל שלילה: un- / in- / im-)
3. סיומות לפי חלק דיבר
4. אסטרטגיות לפתרון
5. טבלאות המרה מהירות
6. מלכודות נפוצות

## 🧩 העקרונות הבסיסיים

### 1. **שורש המילה** (Root)
- הבסיס של המילה
- נושא את המשמעות הראשית
- דוגמה: **act** (פעולה) → act, action, active, react, reaction

### 2. **קידומת** (Prefix)
- מתווספת **לפני** השורש
- משנה את המשמעות
- דוגמה: **un-** + happy = unhappy (לא שמח)

### 3. **סיומת** (Suffix)
- מתווספת **אחרי** השורש
- לרוב משנה חלק דיבר
- דוגמה: act (v) + **-ion** = action (n)

## 📋 קידומות חשובות (Prefixes)

### קידומות של שלילה:
| קידומת | משמעות | דוגמה |
|---|---|---|
| **un-** | לא | un + happy = unhappy |
| **in-** | לא | in + active = inactive |
| **im-** | לא (לפני **p, b, m**) | im + **p**ossible = impossible · im + **b**alance = imbalance · im + **m**ature = immature |
| **il-** | לא (לפני l) | il + legal = illegal |
| **ir-** | לא (לפני r) | ir + regular = irregular |
| **dis-** | הפוך | dis + agree = disagree |
| **non-** | לא | non + sense = nonsense |
| **anti-** | נגד | anti + social = antisocial |
| **mis-** | לא נכון | mis + understand = misunderstand |

**מתי un- ומתי in-?** אין כלל אחד שמכסה את כל המילים – צריך לזכור לפי מילה. כיוון כללי:

| קידומת | נוטה להופיע עם… | דוגמאות |
|---|---|---|
| **un-** | מילים "יומיומיות" יותר, תארים רבים | unhappy, unfair, unclear, unexpected |
| **in-** (וצורותיה im-/il-/ir-) | מילים לטיניות/אקדמיות יותר | inactive, incomplete, impossible, illegal, irregular |

**טיפ למבחן:** אם המילה מתחילה ב־**p / b / m** והקידומת שלילית – בדקו קודם **im-** (impossible, imbalance, immature). אם מתחילה ב־**l** → **il-**; ב־**r** → **ir-**. אחרת – נסו **in-** או **un-** לפי המילה המוכרת לכם.

### קידומות של זמן ומקום:
| קידומת | משמעות | דוגמה |
|---|---|---|
| **pre-** | לפני | pre + pay = prepay |
| **post-** | אחרי | post + war = postwar |
| **re-** | שוב | re + do = redo |
| **sub-** | מתחת | sub + way = subway |
| **super-** | מעל | super + man = superman |
| **trans-** | מעבר | trans + port = transport |
| **inter-** | בין | inter + national = international |

### קידומות של מידה:
| קידומת | משמעות | דוגמה |
|---|---|---|
| **over-** | יותר מדי | over + work = overwork |
| **under-** | פחות מדי | under + estimate = underestimate |
| **multi-** | הרבה | multi + media = multimedia |
| **semi-** | חצי | semi + circle = semicircle |
| **ultra-** | מאוד | ultra + modern = ultramodern |

## 📋 סיומות חשובות (Suffixes)

### סיומות של **שם עצם** (Noun):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-tion / -sion** | פעולה / שם פעולה | educate → education, decide → decision |
| **-ment** | מצב/פעולה | develop → development |
| **-ness** | איכות | happy → happiness |
| **-ity / -ty** | איכות | real → reality |
| **-er / -or** | אדם | teach → teacher |
| **-ist** | אדם עם מקצוע | art → artist |
| **-ism** | אידיאולוגיה | capital → capitalism |
| **-ship** | מצב/יחס | friend → friendship |
| **-hood** | מצב | child → childhood |
| **-dom** | מצב | free → freedom |
| **-ance / -ence** | איכות | import → importance |

### סיומות של **תואר** (Adjective):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-ful** | מלא ב- | beauty → beautiful |
| **-less** | ללא | hope → hopeless |
| **-able / -ible** | ניתן ל- | read → readable |
| **-al** | של / שייך ל- | nature → natural |
| **-ous** | מלא ב- | danger → dangerous |
| **-ive** | נוטה ל- | act → active |
| **-ic** | של / שייך ל- | hero → heroic |
| **-y** | מלא ב- | rain → rainy |
| **-ish** | כמו | child → childish |
| **-ed** | שעבר פעולה | interest → interested |
| **-ing** | שעושה פעולה | interest → interesting |

### סיומות של **פועל** (Verb):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-ize / -ise** | להפוך ל- | modern → modernize |
| **-ate** | לעשות | create, generate |
| **-en** | להפוך ל- | short → shorten |
| **-ify** | לעשות | simple → simplify |

### סיומות של **תואר הפועל** (Adverb):
| סיומת | משמעות | דוגמה |
|---|---|---|
| **-ly** | באופן | quick → quickly |

## 🎯 אסטרטגיות לפתרון שאלות

### אסטרטגיה #1: **זהו את חלק הדיבר הנדרש**

שאלו את עצמכם: **איזו מילה חסרה?**
- **פועל (verb)?** – אם אין פועל במשפט
- **שם עצם (noun)?** – אחרי `the`, `a`, `an`, או כנושא/מושא
- **תואר (adjective)?** – לפני שם עצם או אחרי to-be
- **תואר הפועל (adverb)?** – מתאר פועל או תואר

### אסטרטגיה #2: **נתחו את ההקשר**

קראו את המשפט המלא!
- **שלילי?** → השתמשו בקידומת שלילה (un-, in-, im-, il-, ir-)
- **עבר?** → הוסיפו -ed
- **אקטיבי?** → הוסיפו -ing
- **אדם?** → הוסיפו -er, -or, -ist

### אסטרטגיה #3: **זהו מילה דומה שאתם מכירים**

אם אתם לא מכירים את המילה הספציפית, חשבו על מילים דומות:
- `educate` → לא בטוחים? חשבו על `education`, `educational`, `educator`
- כולן באותה משפחה!

### אסטרטגיה #4: **בדקו את הסיומת של המילה במילה המקור**

| מה יש לכם | מה אתם רוצים | איך? |
|---|---|---|
| education (n) | to educate (v) | הורידו -ion |
| successful (adj) | success (n) | הורידו -ful |
| quickly (adv) | quick (adj) | הורידו -ly |

## 📊 טבלת המרה מהירה

### מילה אחת → כל הצורות:

#### דוגמה: **educate**
| חלק דיבר | מילה | דוגמה במשפט |
|---|---|---|
| פועל (verb) | educate | She educates children. |
| שם עצם (noun) | education | Education is important. |
| שם עצם (person) | educator | He is a skilled educator. |
| תואר (adjective) | educational | This is an educational video. |
| תואר שלילי | uneducated | Uneducated people struggle. |

#### דוגמה: **succeed**
| חלק דיבר | מילה | דוגמה במשפט |
|---|---|---|
| פועל | succeed | She succeeded in her goal. |
| שם עצם | success | His success was incredible. |
| תואר | successful | A successful businessman. |
| תואר הפועל | successfully | She completed it successfully. |
| תואר שלילי | unsuccessful | The attempt was unsuccessful. |

#### דוגמה: **decide**
| חלק דיבר | מילה | דוגמה במשפט |
|---|---|---|
| פועל | decide | I will decide tomorrow. |
| שם עצם | decision | Her decision was clear. |
| תואר | decisive | A decisive victory. |
| תואר הפועל | decisively | He acted decisively. |
| תואר שלילי | indecisive | An indecisive leader. |

## ⚠️ מלכודות נפוצות

### מלכודת 1: **בחירת הקידומת השלילית הלא נכונה**

**כלל צלילי:**
- לפני **L** → **il-** (legal → illegal)
- לפני **R** → **ir-** (regular → irregular)
- לפני **P, B, M** → **im-** (possible → impossible · balance → imbalance · mature → immature)
- אחרים בלטינית/אקדמית → **in-** (active → inactive)
- מילים יומיומיות רבות → **un-** (happy → unhappy · clear → unclear)

זכרו: **un-** ו־**in-** לא תמיד מתחלפים. "inpossible" ו־"unpossible" שגויים; הצורה הנכונה היא **impossible**.

### מלכודת 2: **בחירת הסיומת הלא נכונה / איות**

**דוגמה:**
- success → successful (לא "successfull" או "succesful"!)
- necessary → necessarily (לא "necessaryly"!)
- **beauty → beautiful** – שימו לב ל־**כפילות L**: beauty מאבדת את y → beauti + ful = beautiful (שתי אותיות L בסוף המילה: …fu**ll**)

### מלכודת 3: **התעלמות מהקשר השלילי**

לא מספיק שהמשפט "יכול" להיות חיובי בדקדוק – צריך רמז **בתוך המשפט** שמכריח שלילה.

**דוגמה טובה:**
"Nobody saw it coming; the announcement was completely _____ (expect)."
- ❌ expected (סותר את "Nobody saw it coming")
- ✅ unexpected (מתאים לרמז השלילי)

בלי רמז כזה, גם "expected" וגם "unexpected" יכולים להיות תקינים תחבירית – ולכן במבחן תמיד יש רמז בהקשר.

### מלכודת 4: **שכחת הכפלה של אותיות**

- happy → happiness (לא "hapiness" – כפילות p)
- beauty → beautiful (כפילות L, כפי שצוין למעלה)

## 📝 טיפים לשימוש בזמן מבחן

### 💡 טיפ 1: **קראו את כל המשפט תחילה**

אל תמלאו את החסר מיד – קראו את המשפט, הבינו את המשמעות.

### 💡 טיפ 2: **זהו את חלק הדיבר**

סמנו בעיפרון:
- לפני שם עצם → צריך תואר
- אחרי to-be → צריך תואר
- כנושא/מושא → שם עצם
- אחרי פועל → תואר הפועל

### 💡 טיפ 3: **שאלו: חיובי או שלילי?**

מילים כמו `not`, `without`, `nobody`, `lack of` מאותתות על שלילה.

### 💡 טיפ 4: **בדקו תחבירית**

האם הצורה שלכם מתיישבת עם המשפט?
- **Singular/Plural?**
- **Past/Present/Future?**

## 🎓 דוגמאות לתרגול מהיר

**קריאה פעילה:** ספרו את חלק הדיבר של המילה הנכונה.

### דוגמה 1:
"The ancient civilization had many _____ (achieve)."

- לפני _____ יש "many" (הרבה) → צריך שם עצם ברבים
- **תשובה: achievements** (הישגים)

### דוגמה 2:
"Nobody had predicted the result; the outcome was totally _____ (expect)."

- אחרי to-be → תואר
- "Nobody had predicted" מכריח שלילה
- **תשובה: unexpected** (לא צפוי)

### דוגמה 3:
"She spoke _____ (clear) during the presentation."

- מתאר פועל (spoke) → תואר הפועל
- **תשובה: clearly** (בבירור)

### דוגמה 4:
"The project's _____ (succeed) was due to hard work."

- אחרי "project's" → שם עצם
- **תשובה: success** (הצלחה)

### דוגמה 5:
"It was _____ (possible) to finish on time without more staff."

- אחרי to-be → תואר
- ההקשר ("without more staff") מרמז שלא היה אפשרי
- **תשובה: impossible** (בלתי אפשרי) – ושימו לב ל־**im-** לפני p
