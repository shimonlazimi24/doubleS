## 📝 איך להשתמש בגיליון הזה

1. **העתק את הטבלאות** למסמך גוגל או אקסל (או רשום במחברת)
2. **מלא אחרי כל פעילות** - סימולציה, מבחן תרגול, או שיעור
3. **חזור אליו פעם בשבוע** לבדוק דפוסים
4. **השתמש בו לפני המבחן האמיתי** לראות כמה רחוק הגעת

## 🎯 חלק ג': מעקב אוצר מילים

### שיטת הסימון
לפני שאתה לומד מילה חדשה:
- **V** = אני מכיר את המילה
- **X** = לא מכיר
- **?** = שמעתי/ראיתי אבל לא בטוח

אחרי שבוע של למידה - חזור ובדוק כמה עברו מ-X ל-V.

| חבילה | מילים סה"כ | ידעתי מראש | למדתי | שליטה מלאה |
|---|---|---|---|---|
| חבילה 1 - Easy | 500 | | | |
| חבילה 2 - Intermediate | 500 | | | |
| חבילה 3 - Advanced | 500 | | | |
| חבילה 4 - Expert | 500 | | | |
| Phrasal Verbs | 100 | | | |
| Connectives | 50 | | | |
| **סה"כ** | **2,150** | | | |

### יעד מומלץ:
- **שבוע 1-2:** שליטה בחבילה 1
- **שבוע 3-4:** שליטה בחבילה 2
- **שבוע 5-6:** שליטה בחבילה 3
- **שבוע 7-8:** שליטה בחבילה 4 + Phrasal Verbs + Connectives

## 🎯 חלק ט': בדיקת מוכנות למבחן האמיתי

### צ'קליסט - תסמן כשאתה מרגיש שהגעת ליעד:

#### אוצר מילים
- [ ] שולט ב-2000 המילים הבסיסיות
- [ ] שולט ב-Phrasal Verbs הנפוצים
- [ ] שולט במילות קישור (connectives)

#### Sentence Completion
- [ ] מזהה Collocations נפוצים
- [ ] מזהה מילות רמז (ניגוד, סיבה)
- [ ] לא נופל בזוגות מילים דומות
- [ ] מבחן SC Mixed #2 = 80%+

#### Restatement
- [ ] מזהה Active/Passive
- [ ] שולט ב-Conditionals (1st, 2nd, 3rd)
- [ ] זוכר Inversion structures
- [ ] מבחן Rest Mixed #2 = 80%+

#### Reading Comprehension
- [ ] סורק קטע ב-30 שניות ומבין את הטון
- [ ] מבחין בין Main Idea ל-Detail
- [ ] מזהה Inference סביר מרחוק
- [ ] מבחן RC Mixed #2 = 70%+

#### סימולציות
- [ ] עשיתי לפחות 3 סימולציות
- [ ] הציון עקבי (±2 שאלות) בשתי הסימולציות האחרונות
- [ ] אני עומד בזמן של כל הפרקים

#### מנטלית
- [ ] אני רגוע בסימולציה, לא מתלחץ
- [ ] יש לי תוכנית ליום המבחן (מתי להגיע, מה לאכול)
- [ ] אני מאמין שאני מוכן (או יודע מה עוד לעשות)

### ציון:
- **25+ ✅** = אתה מוכן. גש למבחן!
- **20-24 ✅** = כמעט שם. עוד שבוע-שבועיים של עבודה
- **15-19 ✅** = עוד 3-4 שבועות
- **פחות מ-15** = עוד 6+ שבועות
