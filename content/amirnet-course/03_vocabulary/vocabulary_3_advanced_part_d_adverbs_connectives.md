# 🎯 קטגוריה 1: תארי פועל מתקדמים (20 מילים)

### 1451. **inherently** (adv.)
- **Definition:** by nature
- **תרגום:** מטבעו
- **Example 1:** It's **inherently** dangerous.
- **Example 2:** Humans are **inherently** social.
- **Synonyms:** naturally, intrinsically
- **💡 Memory tip:** מ-`inherent`.

### 1452. **fundamentally** (adv.)
- **Definition:** in a basic way
- **תרגום:** ביסודו
- **Example 1:** **Fundamentally**, we agree.
- **Example 2:** The theory is **fundamentally** flawed.
- **Synonyms:** basically, essentially
- **💡 Memory tip:** מ-`fundamental`.

### 1453. **essentially** (adv.)

- **תרגום:** בעיקרון

# 🔗 קטגוריה 2: מילות קישור אקדמיות גבוהות (15 מילים)

### 1471. **likewise** (adv.)
- **Definition:** in the same way
- **תרגום:** כמו כן, באותו אופן
- **Example 1:** She left, and **likewise** did he.
- **Example 2:** **Likewise**, I enjoyed it.
- **Synonyms:** similarly, also
- **💡 Memory tip:** `like-wise` = כמו שנעשה.

### 1472. **similarly** (adv.)
- **Definition:** in a similar way
- **תרגום:** באופן דומה
- **Example 1:** **Similarly**, we can apply this rule.
- **Example 2:** She behaves **similarly** to him.
- **Synonyms:** likewise
- **💡 Memory tip:** מ-`similar`.

### 1473. **conversely** (adv.)

### 1476. **subsequently** (adv.)

### 1477. **initially** (adv.)

### 1479. **hitherto** (adv.)

### 1480. **whereby** (adv.)
- **Definition:** by which
- **תרגום:** שבאמצעותו
- **Example 1:** A system **whereby** everyone benefits.
- **Example 2:** The method **whereby** we operate.

### 1481. **notwithstanding** (prep./adv.)

### 1482. **albeit** (conj.)

### 1483. **wherein** (adv.)

- **Example 1:** A world **wherein** peace reigns.
- **Example 2:** The situation **wherein** we find ourselves.
- **Synonyms:** in which
- **💡 Memory tip:** `where` + `in`.

### 1484. **heretofore** (adv.)
- **Definition:** up until now
- **תרגום:** עד כה
- **Example 1:** **Heretofore** unmentioned facts.
- **Example 2:** **Heretofore**, we've been lucky.
- **Synonyms:** hitherto, previously
- **💡 Memory tip:** פורמלי - משפטי.

### 1485. **vis-à-vis** (prep.)

## 🧠 לקחים מפתח מחבילה 3:

### 1. **המילים האקדמיות החיוניות למבחן**
הפעלים הכי חשובים:
- `assert`, `contend`, `maintain` - לטעון
- `substantiate`, `corroborate`, `refute` - לבסס/להפריך
- `infer`, `deduce`, `imply` - להסיק/לרמוז

שמות העצם הכי חשובים:
- `hypothesis`, `phenomenon`, `paradigm`
- `implication`, `ramification`, `consequence`
- `discrepancy`, `contradiction`, `anomaly`

### 2. **מילות קישור פורמליות לכתיבה**
- `notwithstanding`, `albeit`, `whereby`
- `hence`, `thereby`, `henceforth`
- `thus`, `consequently`, `accordingly`

### 3. **תארים אקדמיים בעלי ערך**
- `profound`, `pervasive`, `prevalent`
- `intrinsic`, `inherent`, `underlying`
- `empirical`, `quantitative`, `qualitative`
