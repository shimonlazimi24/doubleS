# ➕ קטגוריה 1: קישורי הוספה (10 מילים)

### 2101. **in addition** (phrase)
- **Definition:** also; as well
- **תרגום:** בנוסף
- **Example 1:** **In addition**, we need more funds.
- **Example 2:** She's smart, **in addition** to being talented.
- **Synonyms:** furthermore, moreover
- **💡 Memory tip:** להוספת מידע.

### 2102. **additionally** (adv.)
- **Definition:** in addition; also
- **תרגום:** בנוסף לכך
- **Example 1:** **Additionally**, there are risks.
- **Example 2:** **Additionally**, we must consider cost.
- **Synonyms:** moreover, furthermore
- **💡 Memory tip:** מ-`additional`.

### 2103. **not only... but also** (phrase)
- **Definition:** both X and Y
- **תרגום:** לא רק... אלא גם
- **Example 1:** She's **not only** smart **but also** kind.
- **Example 2:** **Not only** does it work, **but it also** saves money.
- **Synonyms:** both...and
- **💡 Memory tip:** בסדר קבוע: not only + fact 1, but also + fact 2.

### 2104. **as well as** (conj.)
- **Definition:** in addition to
- **תרגום:** כמו גם
- **Example 1:** English, **as well as** Hebrew, is taught.
- **Example 2:** He plays tennis **as well as** basketball.
- **Synonyms:** and, along with
- **💡 Memory tip:** להוספה עם השוואה.

### 2105. **along with** (prep.)
- **Definition:** together with
- **תרגום:** יחד עם
- **Example 1:** Send the form **along with** payment.
- **Example 2:** **Along with** others, she voted.
- **Synonyms:** together with
- **💡 Memory tip:** צירוף יחד.

### 2106. **including** (prep.)
- **Definition:** containing among others
- **תרגום:** כולל
- **Example 1:** All countries, **including** Israel.
- **Example 2:** Many benefits, **including** health.
- **Synonyms:** comprising
- **💡 Memory tip:** מ-`include`.

### 2107. **not to mention** (phrase)
- **Definition:** also; especially
- **תרגום:** שלא לומר
- **Example 1:** It's expensive, **not to mention** slow.
- **Example 2:** She's gifted, **not to mention** hardworking.
- **Synonyms:** let alone, besides
- **💡 Memory tip:** להדגשת פרט נוסף.

### 2108. **let alone** (phrase)
- **Definition:** much less; not to mention
- **תרגום:** קל וחומר
- **Example 1:** He can't walk, **let alone** run.
- **Example 2:** We can't afford it, **let alone** buy two.
- **Synonyms:** much less
- **💡 Memory tip:** להדגשה בשלילה.

### 2109. **on top of that** (phrase)
- **Definition:** in addition
- **תרגום:** ומעל הכל
- **Example 1:** It's cold. **On top of that**, it's raining.
- **Example 2:** **On top of that**, she won.
- **Synonyms:** furthermore, besides
- **💡 Memory tip:** casual.

### 2110. **for good measure** (phrase)
- **Definition:** as an extra
- **תרגום:** בנוסף, למידה טובה
- **Example 1:** Add salt, and pepper **for good measure**.
- **Example 2:** She smiled **for good measure**.
- **Synonyms:** additionally, as a bonus
- **💡 Memory tip:** להוספה קטנה.

# 🔀 קטגוריה 2: קישורי ניגוד (10 מילים)

### 2111. **on the other hand** (phrase)
- **Definition:** from another perspective
- **תרגום:** מצד שני
- **Example 1:** It's expensive. **On the other hand**, it's quality.
- **Example 2:** I like it. **On the other hand**, it's risky.
- **Synonyms:** however, conversely
- **💡 Memory tip:** ניגוד מאוזן.

### 2112. **in contrast** (phrase)
- **Definition:** differently from
- **תרגום:** לעומת זאת
- **Example 1:** **In contrast**, this method is slow.
- **Example 2:** **In contrast** to her brother, she's quiet.
- **Synonyms:** conversely, on the other hand
- **💡 Memory tip:** ניגוד ברור.

### 2113. **in comparison** (phrase)
- **Definition:** when compared
- **תרגום:** בהשוואה
- **Example 1:** **In comparison**, he's more experienced.
- **Example 2:** **In comparison** to others, we did well.
- **Synonyms:** comparatively
- **💡 Memory tip:** להשוואה.

### 2114. **on the contrary** (phrase)
- **Definition:** the opposite is true
- **תרגום:** להיפך
- **Example 1:** It's not boring. **On the contrary**, it's fascinating.
- **Example 2:** **On the contrary**, she loved it.
- **Synonyms:** conversely
- **💡 Memory tip:** לסתירה מוחלטת.

### 2115. **even so** (phrase)
- **Definition:** nevertheless
- **תרגום:** למרות זאת
- **Example 1:** It was hard. **Even so**, we succeeded.
- **Example 2:** **Even so**, I'll try.
- **Synonyms:** nevertheless, still
- **💡 Memory tip:** חיבור למרות התנאי.

### 2116. **in spite of** (prep.)
- **Definition:** despite
- **תרגום:** למרות
- **Example 1:** **In spite of** the rain, we went.
- **Example 2:** **In spite of** his age, he's active.
- **Synonyms:** despite, notwithstanding
- **💡 Memory tip:** פורמלי - זהה ל-despite.

### 2117. **regardless of** (prep.)
- **Definition:** without consideration of
- **תרגום:** ללא תלות ב-
- **Example 1:** **Regardless of** cost, we'll buy it.
- **Example 2:** **Regardless of** the weather.
- **Synonyms:** notwithstanding
- **💡 Memory tip:** להתעלמות מתנאי.

### 2118. **yet** (conj.)
- **Definition:** but; nevertheless
- **תרגום:** ובכל זאת
- **Example 1:** It's small, **yet** powerful.
- **Example 2:** She tried, **yet** failed.
- **Synonyms:** but, however
- **💡 Memory tip:** גם תואר פועל: עדיין.

### 2119. **whereas** - already covered in Package 2.

### 2119. **on the flip side** (phrase)
- **Definition:** on the other hand (informal)
- **תרגום:** מצד שני (לא פורמלי)
- **Example 1:** **On the flip side**, there are risks.
- **Example 2:** **On the flip side**, it's cheap.
- **Synonyms:** on the other hand
- **💡 Memory tip:** casual.

### 2120. **by contrast** (phrase)
- **Definition:** differently; in opposition
- **תרגום:** בניגוד
- **Example 1:** **By contrast**, she's shy.
- **Example 2:** **By contrast**, the new method works.
- **Synonyms:** in contrast
- **💡 Memory tip:** פורמלי.

# 🔗 קטגוריה 3: קישורי סיבה ותוצאה (10 מילים)

### 2121. **due to** (prep.)
- **Definition:** because of
- **תרגום:** בגלל
- **Example 1:** Cancelled **due to** rain.
- **Example 2:** **Due to** traffic, I was late.
- **Synonyms:** because of, owing to
- **💡 Memory tip:** פורמלי - לסיבות.

### 2122. **owing to** (prep.)
- **Definition:** because of
- **תרגום:** בגלל, עקב
- **Example 1:** **Owing to** illness, she missed class.
- **Example 2:** **Owing to** high demand, prices rose.
- **Synonyms:** due to, because of
- **💡 Memory tip:** פורמלי מאוד.

### 2123. **thanks to** (prep.)
- **Definition:** because of (positive)
- **תרגום:** בזכות
- **Example 1:** **Thanks to** her, we succeeded.
- **Example 2:** **Thanks to** technology, we connect.
- **Synonyms:** because of
- **💡 Memory tip:** לרוב חיובי.

### 2124. **as a result** (phrase)
- **Definition:** consequently
- **תרגום:** כתוצאה מכך
- **Example 1:** **As a result**, prices fell.
- **Example 2:** Rain fell heavily. **As a result**, floods occurred.
- **Synonyms:** consequently, therefore
- **💡 Memory tip:** לתוצאה ברורה.

### 2125. **for this reason** (phrase)
- **Definition:** because of this
- **תרגום:** מסיבה זו
- **Example 1:** **For this reason**, we refuse.
- **Example 2:** **For this reason**, security was tight.
- **Synonyms:** therefore, hence
- **💡 Memory tip:** פורמלי.

### 2126. **given that** (conj.)
- **Definition:** considering that
- **תרגום:** בהתחשב בכך ש-
- **Example 1:** **Given that** time is short, let's decide.
- **Example 2:** **Given that** she's tired, rest.
- **Synonyms:** considering that, since
- **💡 Memory tip:** בהתחשב ב-.

### 2127. **seeing that** (conj.)
- **Definition:** since; because
- **תרגום:** מאחר ש-
- **Example 1:** **Seeing that** it's late, let's go.
- **Example 2:** **Seeing that** you agreed, proceed.
- **Synonyms:** since, because
- **💡 Memory tip:** מבוסס על מה שרואים.

### 2128. **on account of** (prep.)
- **Definition:** because of
- **תרגום:** בשל, בגלל
- **Example 1:** **On account of** rain, it was cancelled.
- **Example 2:** **On account of** his age.
- **Synonyms:** because of, due to
- **💡 Memory tip:** פורמלי.

### 2129. **in order to** (conj.)
- **Definition:** with the purpose of
- **תרגום:** על מנת
- **Example 1:** Study **in order to** succeed.
- **Example 2:** Save **in order to** buy a house.
- **Synonyms:** so as to
- **💡 Memory tip:** לציון מטרה.

### 2130. **so that** (conj.)
- **Definition:** with the result that
- **תרגום:** כדי ש-
- **Example 1:** I study **so that** I can pass.
- **Example 2:** Be quiet **so that** they can sleep.
- **Synonyms:** in order that
- **💡 Memory tip:** לציון מטרה/תוצאה.

# 📝 קטגוריה 4: קישורי דוגמה וסיכום (10 מילים)

- **Definition:** such as
- **תרגום:** לדוגמה
- **Example 1:** Many fruits, **for example** apples, are healthy.
- **Example 2:** **For example**, consider this case.
- **Synonyms:** for instance, such as
- **💡 Memory tip:** קיצור נפוץ: e.g.

### 2132. **for instance** (phrase)
- **Definition:** for example
- **תרגום:** לדוגמה
- **Example 1:** **For instance**, take this case.
- **Example 2:** Many issues, **for instance** health, matter.
- **Synonyms:** for example
- **💡 Memory tip:** דומה ל-`for example`.

### 2133. **such as** (phrase)

- **תרגום:** כגון
- **Example 1:** Fruits **such as** apples are healthy.
- **Example 2:** Cities **such as** London and Paris.
- **Synonyms:** like, including

### 2134. **to illustrate** (phrase)

### 2135. **namely** (adv.)

### 2137. **in conclusion** (phrase)

- **Example 2:** **In conclusion**, the study succeeded.
- **Synonyms:** finally, to conclude
- **💡 Memory tip:** לסיום רשמי.

### 2138. **overall** (adv.)

- **Synonyms:** in general, altogether

### 2139. **in short** (phrase)

- **תרגום:** בקצרה
- **Example 1:** **In short**, it failed.
- **Example 2:** **In short**, we must act.
- **Synonyms:** briefly, in summary

### 2140. **all in all** (phrase)
- **Definition:** taking everything into consideration

## 🧠 טבלת בחירת קישורים:

### להוספה:
- **פשוט:** and, also
- **בינוני:** in addition, as well as
- **פורמלי:** moreover, furthermore, additionally

### לניגוד:
- **פשוט:** but
- **בינוני:** however, on the other hand
- **פורמלי:** nevertheless, nonetheless, conversely

### לסיבה/תוצאה:
- **פשוט:** because, so
- **בינוני:** due to, therefore, as a result
- **פורמלי:** consequently, hence, thus, accordingly

### לדוגמה:
- **פשוט:** like, for example
- **בינוני:** such as, for instance
- **פורמלי:** namely, to illustrate

**אל תחזרו על אותה מילת קישור כל הזמן!**
