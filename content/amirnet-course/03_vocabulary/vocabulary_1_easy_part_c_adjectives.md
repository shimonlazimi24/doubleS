# 📏 קטגוריה 1: גודל ומידה (20 מילים)

### 351. **big** (adj.)
- **Definition:** large in size
- **תרגום:** גדול
- **Example 1:** They live in a **big** house.
- **Example 2:** She has a **big** smile.
- **Synonyms:** large, huge, enormous
- **Antonyms:** small, little
- **💡 Memory tip:** `bigger`, `biggest` - comparative/superlative.

### 352. **small** (adj.)
- **Definition:** little in size
- **תרגום:** קטן
- **Example 1:** This is a **small** room.
- **Example 2:** I have a **small** dog.
- **Synonyms:** little, tiny
- **Antonyms:** big, large
- **💡 Memory tip:** `smaller`, `smallest`.

### 353. **large** (adj.)
- **Definition:** big in size
- **תרגום:** גדול (פורמלי יותר)
- **Example 1:** We need a **large** table.
- **Example 2:** A **large** crowd gathered.
- **Synonyms:** big, huge
- **Antonyms:** small
- **💡 Memory tip:** `large` פורמלי יותר מ-`big`.

### 354. **huge** (adj.)
- **Definition:** very big
- **תרגום:** עצום, ענק
- **Example 1:** The elephant is **huge**.
- **Example 2:** That's a **huge** problem.
- **Synonyms:** enormous, massive, gigantic
- **Antonyms:** tiny, small
- **💡 Memory tip:** חזק יותר מ-"big" או "large".

### 355. **tiny** (adj.)
- **Definition:** extremely small
- **תרגום:** זעיר
- **Example 1:** She has a **tiny** puppy.
- **Example 2:** Only a **tiny** amount is needed.
- **Synonyms:** small, little, minute
- **Antonyms:** huge, enormous
- **💡 Memory tip:** קטן במיוחד.

### 356. **tall** (adj.)
- **Definition:** of great height
- **תרגום:** גבוה (אדם/עץ)
- **Example 1:** He is very **tall**.
- **Example 2:** The **tall** tree gives nice shade.
- **Synonyms:** high
- **Antonyms:** short
- **💡 Memory tip:** `tall` לאנשים/עצים. `high` למקומות/מחיר.

### 357. **short** (adj.)
- **Definition:** small in height; brief
- **תרגום:** נמוך; קצר
- **Example 1:** She is **short**.
- **Example 2:** It was a **short** trip.
- **Synonyms:** little (height); brief (time)
- **Antonyms:** tall; long
- **💡 Memory tip:** שני מובנים: גובה או משך זמן.

### 358. **high** (adj.)
- **Definition:** at a great height; significant
- **תרגום:** גבוה (מקום, מחיר)
- **Example 1:** The mountain is very **high**.
- **Example 2:** The price is too **high**.
- **Synonyms:** tall, elevated
- **Antonyms:** low
- **💡 Memory tip:** `high` למיקום/מחיר; `tall` לאנשים.

### 359. **low** (adj.)

### 367. **full** (adj.)

### 368. **empty** (adj.)

- **Synonyms:** bare, vacant

### 369. **far** (adj./adv.)

## 🧠 כללי זהב לתארים:

### 1. **Comparative ו-Superlative**
- **One syllable:** big → bigger → biggest
- **Two+ syllables:** important → more important → most important
- **ירידות חריגות:** good → better → best; bad → worse → worst

### 2. **-ed vs -ing**
- **-ed** = ההרגשה שלך: "I'm **bored**" (אני משועמם)
- **-ing** = הגורם: "The movie is **boring**" (הסרט משעמם)

### 3. **סדר התארים**
באנגלית יש סדר קבוע:
- opinion → size → age → shape → color → origin → material → purpose
- דוגמה: "a beautiful little old round red French wooden dining table"

### 4. **תארים שאינם לוקחים -er/-est**
- Don't say: "more best", "more interesting*er*"
- Use: "more interesting", "the most interesting"
