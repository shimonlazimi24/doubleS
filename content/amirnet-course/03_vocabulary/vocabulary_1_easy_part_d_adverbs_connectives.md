# 🏃 קטגוריה 1: תארי פועל של אופן ודרך (15 מילים)

### 451. **quickly** (adv.)
- **Definition:** at a fast speed
- **תרגום:** במהירות
- **Example 1:** She **quickly** finished her work.
- **Example 2:** The children ran **quickly**.
- **Synonyms:** fast, rapidly, swiftly
- **Antonyms:** slowly
- **💡 Memory tip:** מ-"quick" + -ly.

### 452. **slowly** (adv.)
- **Definition:** at a slow speed
- **תרגום:** לאט
- **Example 1:** Please speak **slowly**.
- **Example 2:** The train moved **slowly**.
- **Synonyms:** gradually
- **Antonyms:** quickly, fast
- **💡 Memory tip:** מ-"slow" + -ly.

### 453. **carefully** (adv.)
- **Definition:** with attention and care
- **תרגום:** בזהירות
- **Example 1:** Read the instructions **carefully**.
- **Example 2:** She drives **carefully**.
- **Synonyms:** cautiously, attentively
- **Antonyms:** carelessly
- **💡 Memory tip:** `carefully` = "full of care".

### 454. **easily** (adv.)
- **Definition:** without difficulty
- **תרגום:** בקלות
- **Example 1:** She solved the problem **easily**.
- **Example 2:** He can **easily** lift 100 kilograms.
- **Synonyms:** effortlessly, simply
- **Antonyms:** with difficulty
- **💡 Memory tip:** `easy` → `easily`.

### 455. **badly** (adv.)
- **Definition:** in a bad way; very much
- **תרגום:** בצורה גרועה; מאוד
- **Example 1:** He plays football **badly**.
- **Example 2:** I **badly** need a vacation.
- **Synonyms:** poorly
- **Antonyms:** well
- **💡 Memory tip:** שני שימושים: איכות גרועה / הדגשה חזקה.

### 456. **well** (adv.)
- **Definition:** in a good way; correctly
- **תרגום:** היטב
- **Example 1:** She speaks English **well**.
- **Example 2:** Did you sleep **well**?
- **Synonyms:** properly, effectively
- **Antonyms:** badly, poorly
- **💡 Memory tip:** חריג! `good` (adj) → `well` (adv), לא "goodly".

### 457. **hard** (adv.)
- **Definition:** with great effort
- **תרגום:** קשה (במאמץ)
- **Example 1:** She works **hard**.
- **Example 2:** Try **hard** and you'll succeed.
- **Synonyms:** with effort, vigorously
- **Antonyms:** easily
- **💡 Memory tip:** "hard" עצמו הוא adv! לא "hardly".

### 458. **hardly** (adv.)
- **Definition:** almost not; barely
- **תרגום:** כמעט ולא, בקושי
- **Example 1:** I **hardly** know him.
- **Example 2:** She **hardly** eats anything.
- **Synonyms:** barely, scarcely
- **Antonyms:** frequently
- **💡 Memory tip:** **חשוב!** `hard` = קשה. `hardly` = כמעט ולא. שונים לגמרי!

### 459. **almost** (adv.)
- **Definition:** very nearly
- **תרגום:** כמעט
- **Example 1:** I'm **almost** finished.
- **Example 2:** It's **almost** 5 o'clock.
- **Synonyms:** nearly
- **Antonyms:** exactly
- **💡 Memory tip:** `almost` = almost there (כמעט שם).

### 460. **nearly** (adv.)
- **Definition:** almost
- **תרגום:** כמעט
- **Example 1:** I **nearly** fell.
- **Example 2:** She's **nearly** 18 years old.
- **Synonyms:** almost
- **Antonyms:** completely, exactly
- **💡 Memory tip:** `almost` ו-`nearly` = כמעט זהים.

### 461. **completely** (adv.)
- **Definition:** entirely; totally
- **תרגום:** לגמרי
- **Example 1:** I **completely** agree with you.
- **Example 2:** The work is **completely** finished.
- **Synonyms:** totally, fully, entirely
- **Antonyms:** partially
- **💡 Memory tip:** `complete` + -ly.

### 462. **totally** (adv.)
- **Definition:** completely
- **תרגום:** לגמרי, בסך הכל
- **Example 1:** I **totally** forgot about the meeting.
- **Example 2:** That's **totally** fine.
- **Synonyms:** completely, entirely
- **Antonyms:** partially
- **💡 Memory tip:** גם casual: "totally!" = "לגמרי!".

### 463. **really** (adv.)
- **Definition:** very; actually
- **תרגום:** באמת, מאוד
- **Example 1:** I'm **really** tired.
- **Example 2:** Is that **really** true?
- **Synonyms:** very, actually, truly
- **Antonyms:** slightly
- **💡 Memory tip:** תואר פועל נפוץ מאוד בדיבור יומיומי.

### 464. **very** (adv.)
- **Definition:** to a high degree
- **תרגום:** מאוד
- **Example 1:** This is **very** important.
- **Example 2:** She's **very** happy today.
- **Synonyms:** extremely, really
- **Antonyms:** slightly
- **💡 Memory tip:** **לא** להשתמש לפני comparatives ("very bigger" = שגוי!).

### 465. **too** (adv.)
- **Definition:** more than needed; also
- **תרגום:** יותר מדי; גם
- **Example 1:** It's **too** hot to play outside.
- **Example 2:** I want to come **too**.
- **Synonyms:** excessively; also
- **💡 Memory tip:** שני מובנים! "too hot" = חם מדי. "me too" = אני גם.

# ⏱️ קטגוריה 2: תארי פועל של זמן ותדירות (15 מילים)

### 466. **always** (adv.)
- **Definition:** at all times
- **תרגום:** תמיד
- **Example 1:** She **always** arrives on time.
- **Example 2:** I will **always** remember this day.
- **Synonyms:** constantly, forever
- **Antonyms:** never
- **💡 Memory tip:** 100% - הכי גבוה בתדירות.

### 467. **usually** (adv.)
- **Definition:** most of the time
- **תרגום:** בדרך כלל
- **Example 1:** I **usually** take the bus to work.
- **Example 2:** She **usually** drinks coffee in the morning.
- **Synonyms:** generally, normally
- **Antonyms:** rarely
- **💡 Memory tip:** כ-90% מהזמן.

### 468. **often** (adv.)
- **Definition:** many times
- **תרגום:** לעתים קרובות
- **Example 1:** We **often** go to the beach.
- **Example 2:** How **often** do you exercise?
- **Synonyms:** frequently
- **Antonyms:** rarely, seldom
- **💡 Memory tip:** כ-70% מהזמן. הגייה: /ˈɒfən/ (t שקטה).

### 469. **sometimes** (adv.)
- **Definition:** occasionally
- **תרגום:** לפעמים
- **Example 1:** **Sometimes** I walk to work.
- **Example 2:** She **sometimes** calls her mother.
- **Synonyms:** occasionally, at times
- **Antonyms:** always; never
- **💡 Memory tip:** כ-50% מהזמן.

### 470. **rarely** (adv.)
- **Definition:** not often
- **תרגום:** נדיר
- **Example 1:** I **rarely** eat junk food.
- **Example 2:** He **rarely** talks to strangers.
- **Synonyms:** seldom, hardly ever
- **Antonyms:** often, frequently
- **💡 Memory tip:** כ-10% מהזמן.

### 471. **never** (adv.)
- **Definition:** not at any time
- **תרגום:** אף פעם לא
- **Example 1:** I **never** eat sushi.
- **Example 2:** She has **never** been to Europe.
- **Synonyms:** not ever
- **Antonyms:** always
- **💡 Memory tip:** 0% - ההפך מ-`always`.

### 472. **now** (adv.)
- **Definition:** at this moment
- **תרגום:** עכשיו
- **Example 1:** I'm busy right **now**.
- **Example 2:** We need to leave **now**.
- **Synonyms:** currently, at present
- **Antonyms:** then, later
- **💡 Memory tip:** הרגע הנוכחי.

### 473. **then** (adv.)
- **Definition:** at that time; next
- **תרגום:** אז; אחר כך
- **Example 1:** We ate, **then** we went to the movie.
- **Example 2:** Back **then**, we didn't have phones.
- **Synonyms:** next, afterward
- **Antonyms:** now
- **💡 Memory tip:** שני מובנים: "אז" (אז בעבר) / "אחר כך" (ברצף פעולות).

### 474. **soon** (adv.)
- **Definition:** in a short time
- **תרגום:** בקרוב
- **Example 1:** I'll be there **soon**.
- **Example 2:** She's coming home **soon**.
- **Synonyms:** shortly
- **Antonyms:** later, not yet
- **💡 Memory tip:** `see you soon` = נתראה בקרוב.

### 475. **later** (adv.)
- **Definition:** after the present time
- **תרגום:** מאוחר יותר
- **Example 1:** I'll call you **later**.
- **Example 2:** See you **later**!
- **Synonyms:** afterward, subsequently
- **Antonyms:** earlier, now
- **💡 Memory tip:** `late` + -er = יותר מאוחר.

### 476. **already** (adv.)
- **Definition:** before now; sooner than expected
- **תרגום:** כבר
- **Example 1:** I've **already** finished my homework.
- **Example 2:** She's **already** gone home.
- **Synonyms:** previously, by now
- **Antonyms:** not yet
- **💡 Memory tip:** מופיע עם Present Perfect: "have already V3".

### 477. **yet** (adv.)
- **Definition:** up until now (in questions/negatives)
- **תרגום:** עדיין
- **Example 1:** Have you finished **yet**?
- **Example 2:** I haven't seen that movie **yet**.
- **Synonyms:** still, until now
- **💡 Memory tip:** `yet` - בשאלות ובשלילה; `already` - בחיובי.

### 478. **still** (adv.)
- **Definition:** up to this time; yet continuing
- **תרגום:** עדיין
- **Example 1:** She's **still** waiting for her friend.
- **Example 2:** Are you **still** hungry?
- **Synonyms:** yet, continuously
- **💡 Memory tip:** גם תואר (still = שקט/יציב).

### 479. **just** (adv.)
- **Definition:** very recently; only; exactly
- **תרגום:** רק עכשיו; פשוט
- **Example 1:** I **just** arrived.
- **Example 2:** I **just** want to sleep.
- **Synonyms:** recently; simply
- **💡 Memory tip:** מילה רבת-משמעויות. לרוב מתייחסת לזמן קרוב.

### 480. **once** (adv.)
- **Definition:** one time
- **תרגום:** פעם אחת
- **Example 1:** I visited Paris **once**.
- **Example 2:** She calls her grandmother **once** a week.
- **Synonyms:** one time
- **Antonyms:** never; many times
- **💡 Memory tip:** גם: `once upon a time` = היה היה (תחילת אגדה).

# 🔗 קטגוריה 3: מילות קישור (Connectives) (15 מילים)

### 481. **and** (conj.)
- **Definition:** connects similar ideas
- **תרגום:** ו-, וגם
- **Example 1:** Tom **and** I went to the store.
- **Example 2:** She smiled **and** waved.
- **Synonyms:** also, plus
- **💡 Memory tip:** מילת הקישור הבסיסית ביותר - חיבור.

### 482. **but** (conj.)
- **Definition:** connects contrasting ideas
- **תרגום:** אבל
- **Example 1:** I want to go, **but** I'm tired.
- **Example 2:** She's smart **but** shy.
- **Synonyms:** however, yet
- **💡 Memory tip:** מילת הקישור של **ניגוד**.

### 483. **or** (conj.)
- **Definition:** presents alternatives
- **תרגום:** או
- **Example 1:** Would you like tea **or** coffee?
- **Example 2:** We can go by car **or** bus.
- **Synonyms:** either...or
- **💡 Memory tip:** מילת הקישור של **בחירה**.

### 484. **so** (conj./adv.)
- **Definition:** for this reason; therefore
- **תרגום:** לכן, אז
- **Example 1:** It was raining, **so** we stayed home.
- **Example 2:** I was tired, **so** I went to bed.
- **Synonyms:** therefore, thus
- **💡 Memory tip:** מילת הקישור של **תוצאה**.

### 485. **because** (conj.)
- **Definition:** for the reason that
- **תרגום:** כי, בגלל ש-
- **Example 1:** I'm happy **because** I passed the test.
- **Example 2:** She's late **because** of traffic.
- **Synonyms:** since, as
- **💡 Memory tip:** מילת הקישור של **סיבה**.

### 486. **if** (conj.)
- **Definition:** in the event that
- **תרגום:** אם
- **Example 1:** **If** it rains, we'll stay inside.
- **Example 2:** I'll help you **if** you need it.
- **Synonyms:** in case, provided that
- **💡 Memory tip:** מילת הקישור של **תנאי**.

### 487. **when** (conj./adv.)
- **Definition:** at what time; at the time that
- **תרגום:** מתי; כאשר
- **Example 1:** **When** do you finish work?
- **Example 2:** Call me **when** you arrive.
- **Synonyms:** at the time that
- **💡 Memory tip:** גם לשאלות (מתי?) וגם לקישור.

### 488. **while** (conj.)
- **Definition:** during the time that
- **תרגום:** בזמן ש-, כאשר
- **Example 1:** I read **while** I waited.
- **Example 2:** **While** she cooked, he cleaned.
- **Synonyms:** during, as
- **💡 Memory tip:** שתי פעולות בו-זמנית.

### 489. **before** (prep./conj.)
- **Definition:** at an earlier time than
- **תרגום:** לפני
- **Example 1:** **Before** we leave, let's eat.
- **Example 2:** He arrived **before** noon.
- **Synonyms:** earlier than, prior to
- **Antonyms:** after
- **💡 Memory tip:** במילון של זמן: before.

### 490. **after** (prep./conj.)
- **Definition:** at a later time than
- **תרגום:** אחרי
- **Example 1:** **After** dinner, we watched TV.
- **Example 2:** I'll call you **after** I finish.
- **Synonyms:** following, later than
- **Antonyms:** before
- **💡 Memory tip:** אחרי (זמן / מיקום ברצף).

### 491. **although** (conj.)
- **Definition:** in spite of; even though
- **תרגום:** למרות ש-
- **Example 1:** **Although** it was cold, we went hiking.
- **Example 2:** She smiled **although** she was sad.
- **Synonyms:** even though, despite the fact that
- **💡 Memory tip:** מילה פורמלית ל-"but"; יוצרת ניגוד.

### 492. **however** (adv.)
- **Definition:** on the other hand
- **תרגום:** עם זאת, אולם
- **Example 1:** The plan is good. **However**, it's expensive.
- **Example 2:** I wanted to go; **however**, I was too tired.
- **Synonyms:** nevertheless, but
- **💡 Memory tip:** פורמלי מ-"but". משמש בתחילת משפט עם פסיק.

### 493. **also** (adv.)
- **Definition:** in addition; too
- **תרגום:** גם
- **Example 1:** She's smart and **also** kind.
- **Example 2:** I **also** want to come.
- **Synonyms:** too, as well
- **💡 Memory tip:** `also` באמצע משפט; `too` בסוף.

### 494. **both** (det./pron.)
- **Definition:** the two together
- **תרגום:** שניהם
- **Example 1:** **Both** of us are tired.
- **Example 2:** I like **both** cats and dogs.
- **Synonyms:** the two
- **Antonyms:** neither
- **💡 Memory tip:** `both X and Y` = גם X וגם Y.

### 495. **only** (adv.)
- **Definition:** nothing else; just
- **תרגום:** רק
- **Example 1:** I have **only** 10 minutes.
- **Example 2:** **Only** John can help us.
- **Synonyms:** just, merely
- **💡 Memory tip:** מגביל (limit).

# 💎 קטגוריה 4: ביטויים חשובים (5 מילים)

### 496. **yes** (adv.)
- **Definition:** a positive answer
- **תרגום:** כן
- **Example 1:** "Do you like it?" "**Yes**, I do."
- **Example 2:** **Yes**, please!
- **Synonyms:** yeah (casual), yep (very casual)
- **Antonyms:** no
- **💡 Memory tip:** מילת האישור הבסיסית.

### 497. **no** (adv.)
- **Definition:** a negative answer
- **תרגום:** לא
- **Example 1:** "Are you hungry?" "**No**, thanks."
- **Example 2:** **No**, I disagree.
- **Synonyms:** nope (casual)
- **Antonyms:** yes
- **💡 Memory tip:** מילת השלילה הבסיסית.

### 498. **maybe** (adv.)
- **Definition:** possibly; perhaps
- **תרגום:** אולי
- **Example 1:** **Maybe** I'll come to the party.
- **Example 2:** **Maybe** it will rain tomorrow.
- **Synonyms:** perhaps, possibly
- **💡 Memory tip:** `may + be` = אולי יהיה.

### 499. **please** (adv.)
- **Definition:** used to make polite requests
- **תרגום:** בבקשה
- **Example 1:** Can you help me, **please**?
- **Example 2:** **Please** close the door.
- **Synonyms:** (none)
- **💡 Memory tip:** מילה נימוסית חיונית!

### 500. **thanks** / **thank you**
- **Definition:** words of gratitude
- **תרגום:** תודה / תודה לך
- **Example 1:** **Thanks** for your help!
- **Example 2:** **Thank you** very much.
- **Synonyms:** thanks a lot, many thanks
- **💡 Memory tip:** `thanks` - casual; `thank you` - formal.

## 🧠 כללי זהב לתארי פועל:

### 1. **-ly Rule**
רוב תארי הפועל = תואר + -ly:
- quick → quickly
- slow → slowly  
- careful → carefully

### 2. **תארי פועל חריגים**
- good → **well** (לא "goodly")
- fast → **fast** (נשאר)
- hard → **hard** (נשאר!)
  - `hard` (adv) = קשה, במאמץ
  - `hardly` = כמעט ולא (משמעות שונה!)

### 3. **מיקום תדירות במשפט**
- לפני הפועל: "I **always** eat breakfast."
- אחרי be: "She is **always** happy."
- בתחילת משפט (חריג): "**Sometimes** I walk."

### 4. **Connectives באקדמיה**
רמת פורמליות שונה:
- יומיומי: but, so, because
- פורמלי: however, therefore, since
- אקדמי: nevertheless, consequently, owing to
