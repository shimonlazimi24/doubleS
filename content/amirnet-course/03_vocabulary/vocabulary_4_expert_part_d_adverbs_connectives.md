# ✍️ קטגוריה 1: תארי פועל ספרותיים (25 מילים)

### 1951. **invariably** (adv.)
- **Definition:** always; without exception
- **תרגום:** תמיד, ללא יוצא מן הכלל
- **Example 1:** She **invariably** arrives late.
- **Example 2:** **Invariably**, the result is the same.
- **Synonyms:** always, unfailingly
- **💡 Memory tip:** מ-`invariable`.

### 1952. **unfailingly** (adv.)
- **Definition:** always; without failure
- **תרגום:** ללא כישלון
- **Example 1:** He's **unfailingly** polite.
- **Example 2:** **Unfailingly** reliable.
- **Synonyms:** invariably, always
- **💡 Memory tip:** `un-` + `failing`.

### 1953. **inevitably** (adv.)
- **Definition:** unavoidably
- **תרגום:** באופן בלתי נמנע
- **Example 1:** **Inevitably**, she changed her mind.
- **Example 2:** Mistakes are **inevitably** made.
- **Synonyms:** unavoidably
- **💡 Memory tip:** מ-`inevitable`.

### 1954. **irrevocably** (adv.)
- **Definition:** cannot be changed back
- **תרגום:** באופן בלתי הפיך
- **Example 1:** **Irrevocably** committed.
- **Example 2:** Her decision was **irrevocably** made.
- **Synonyms:** permanently, finally
- **💡 Memory tip:** `ir-` + `revocable`.

### 1955. **indefinitely** (adv.)
- **Definition:** for an unlimited time
- **תרגום:** ללא הגבלה
- **Example 1:** Postponed **indefinitely**.
- **Example 2:** The meeting lasted **indefinitely**.
- **Synonyms:** forever, permanently
- **💡 Memory tip:** מ-`indefinite`.

### 1956. **exceptionally** (adv.)
- **Definition:** unusually; very
- **תרגום:** יוצא מן הכלל
- **Example 1:** **Exceptionally** talented.
- **Example 2:** **Exceptionally** good.
- **Synonyms:** unusually, extraordinarily
- **💡 Memory tip:** מ-`exceptional`.

### 1957. **exponentially** (adv.)
- **Definition:** rapidly increasing
- **תרגום:** באופן מעריכי
- **Example 1:** Growing **exponentially**.
- **Example 2:** Costs rose **exponentially**.
- **Synonyms:** rapidly, dramatically
- **💡 Memory tip:** מ-`exponential`.

### 1958. **profoundly** (adv.)

- **Example 2:** **Profoundly** changed her.

### 1960. **adamantly** (adv.)

# 🔗 קטגוריה 2: מילות קישור פורמליות מאוד (15 מילים)

### 1976. **inasmuch as** (conj.)
- **Definition:** because; since
- **תרגום:** מאחר ש-
- **Example 1:** **Inasmuch as** he agreed, we proceeded.
- **Example 2:** **Inasmuch as** time permits.
- **Synonyms:** since, because
- **💡 Memory tip:** פורמלי מאוד.

### 1977. **whereupon** (adv.)
- **Definition:** immediately after which
- **תרגום:** ובעקבות כך
- **Example 1:** He nodded, **whereupon** we left.
- **Example 2:** **Whereupon** she ran.
- **Synonyms:** at which point
- **💡 Memory tip:** ספרותי ומשפטי.

### 1978. **thereupon** (adv.)
- **Definition:** immediately after that
- **תרגום:** מייד לאחר
- **Example 1:** **Thereupon**, he left.
- **Example 2:** **Thereupon**, the meeting ended.
- **Synonyms:** then, whereupon
- **💡 Memory tip:** פורמלי.

### 1979. **therein** (adv.)
- **Definition:** in that place; in that
- **תרגום:** בתוך כך
- **Example 1:** **Therein** lies the problem.
- **Example 2:** Information contained **therein**.
- **Synonyms:** in that
- **💡 Memory tip:** משפטי ופורמלי.

### 1980. **thereof** (adv.)
- **Definition:** of that
- **תרגום:** של זה
- **Example 1:** The contract and the terms **thereof**.
- **Example 2:** **Thereof** I speak.
- **Synonyms:** of that
- **💡 Memory tip:** משפטי מאוד.

### 1981. **thereto** (adv.)
- **Definition:** to that
- **תרגום:** אליו
- **Example 1:** The agreement **thereto**.
- **Example 2:** Parties **thereto**.
- **Synonyms:** to that
- **💡 Memory tip:** משפטי.

### 1982. **henceforward** (adv.)
- **Definition:** from now on
- **תרגום:** מעתה ואילך
- **Example 1:** **Henceforward**, the policy applies.
- **Example 2:** We must, **henceforward**, be careful.
- **Synonyms:** henceforth, from now on
- **💡 Memory tip:** `hence` + `forward`.

### 1983. **wherewith** (adv.)
- **Definition:** with which
- **תרגום:** אשר בו
- **Example 1:** Tools **wherewith** we build.
- **Example 2:** Means **wherewith** to succeed.
- **Synonyms:** with which
- **💡 Memory tip:** ארכאי.

### 1984. **insofar as** (conj.)
- **Definition:** to the extent that
- **תרגום:** במידה ש-
- **Example 1:** **Insofar as** I know, he's honest.
- **Example 2:** **Insofar as** it's possible.
- **Synonyms:** to the degree that
- **💡 Memory tip:** `in so far as`.

### 1985. **provided that** (conj.)
- **Definition:** if; on condition that
- **תרגום:** בתנאי ש-
- **Example 1:** I'll go, **provided that** you come too.
- **Example 2:** **Provided that** it doesn't rain.
- **Synonyms:** if, on condition that
- **💡 Memory tip:** תנאי פורמלי.

### 1986. **notwithstanding** - already covered at #1481. Skipping.

### 1986. **granted that** (conj.)
- **Definition:** even if; although
- **תרגום:** אף ש-, בהנחה ש-
- **Example 1:** **Granted that** he's talented, he needs training.
- **Example 2:** **Granted that** you tried.
- **Synonyms:** although
- **💡 Memory tip:** קבלת טיעון נגדי.

### 1987. **save for** (prep.)
- **Definition:** except for
- **תרגום:** למעט
- **Example 1:** Empty **save for** a chair.
- **Example 2:** All agreed, **save for** one.
- **Synonyms:** except for, apart from
- **💡 Memory tip:** פורמלי וספרותי.

### 1988. **barring** (prep.)
- **Definition:** except for; unless there is
- **תרגום:** מלבד, אלא אם כן
- **Example 1:** **Barring** accidents, we'll arrive on time.
- **Example 2:** **Barring** unexpected events.
- **Synonyms:** except for, unless
- **💡 Memory tip:** מ-`bar` (חסימה).

### 1989. **in lieu of** (prep.)
- **Definition:** instead of
- **תרגום:** במקום
- **Example 1:** **In lieu of** flowers, donate.
- **Example 2:** Coffee **in lieu of** tea.
- **Synonyms:** instead of, in place of
- **💡 Memory tip:** מצרפתית - `lieu` = מקום.

### 1990. **pursuant to** (prep.)
- **Definition:** in accordance with
- **תרגום:** בהתאם ל-
- **Example 1:** **Pursuant to** the agreement.
- **Example 2:** **Pursuant to** the law.
- **Synonyms:** according to
- **💡 Memory tip:** משפטי מאוד.

# 🏛️ קטגוריה 3: ביטויים לאטיניים נפוצים (10 מילים)

### 1991. **per se** (adv.)
- **Definition:** by itself; intrinsically
- **תרגום:** כשלעצמו
- **Example 1:** Money isn't evil **per se**.
- **Example 2:** Not harmful **per se**.
- **Synonyms:** intrinsically, in itself
- **💡 Memory tip:** לטינית - "דרך עצמו".

### 1992. **ad hoc** (adj./adv.)
- **Definition:** for a specific purpose
- **תרגום:** לצורך מיוחד, אד-הוק
- **Example 1:** An **ad hoc** committee.
- **Example 2:** **Ad hoc** decisions.
- **Synonyms:** improvised, specific
- **💡 Memory tip:** לטינית - "לזה".

### 1993. **vice versa** (adv.)
- **Definition:** the other way around
- **תרגום:** ולהיפך
- **Example 1:** I help you and **vice versa**.
- **Example 2:** Dogs hate cats, and **vice versa**.
- **Synonyms:** conversely
- **💡 Memory tip:** לטינית.

### 1994. **status quo** - already covered at #1788. Skipping.

### 1994. **bona fide** (adj.)
- **Definition:** genuine; real
- **תרגום:** אמיתי, כנה
- **Example 1:** A **bona fide** offer.
- **Example 2:** **Bona fide** intentions.
- **Synonyms:** genuine, authentic
- **💡 Memory tip:** לטינית - "בתום לב".

### 1995. **de facto** (adj./adv.)
- **Definition:** in fact; actually
- **תרגום:** למעשה
- **Example 1:** **De facto** leader.
- **Example 2:** **De facto** state.
- **Synonyms:** in reality, effectively
- **💡 Memory tip:** לטינית - "מן המציאות".

### 1996. **de jure** (adj./adv.)
- **Definition:** by law; legally
- **תרגום:** חוקית, לפי החוק
- **Example 1:** **De jure** recognition.
- **Example 2:** **De jure** vs. **de facto**.
- **Synonyms:** legally
- **Antonyms:** de facto
- **💡 Memory tip:** לטינית - "לפי חוק".

### 1997. **modus operandi** (n.)
- **Definition:** method of operation
- **תרגום:** שיטת פעולה
- **Example 1:** His **modus operandi** is clear.
- **Example 2:** A criminal's **modus operandi**.
- **Synonyms:** method, way
- **💡 Memory tip:** לטינית. קיצור: M.O.

### 1998. **raison d'être** (n.)
- **Definition:** reason for existence
- **תרגום:** סיבה לקיום
- **Example 1:** Work is his **raison d'être**.
- **Example 2:** Find your **raison d'être**.
- **Synonyms:** purpose, justification
- **💡 Memory tip:** צרפתית.

### 1999. **carpe diem** (phrase)
- **Definition:** seize the day
- **תרגום:** קפוץ על ההזדמנות
- **Example 1:** **Carpe diem** - live fully!
- **Example 2:** Her motto is **carpe diem**.
- **Synonyms:** seize the day
- **💡 Memory tip:** לטינית קלאסית.

### 2000. **verbatim** (adv./adj.)
- **Definition:** word for word
- **תרגום:** מילה במילה
- **Example 1:** Quoted **verbatim**.
- **Example 2:** **Verbatim** transcript.
- **Synonyms:** word-for-word, exactly
- **💡 Memory tip:** לטינית - "במילה".
