# Phrasal Verbs – 100 פועלים מורכבים

# 💬 קטגוריה 1: Phrasal Verbs של תקשורת (20 מילים)

### 2001. **bring up** (v.)
- **Definition:** to mention a topic; to raise a child
- **תרגום:** להעלות (נושא); לגדל
- **Example 1:** Don't **bring up** that topic.
- **Example 2:** She was **brought up** in Israel.
- **Synonyms:** mention, raise
- **💡 Memory tip:** "להעלות" - bring up.

### 2002. **point out** (v.)

- **תרגום:** להצביע על, לציין

- **Example 2:** She **pointed out** the mistake.
- **Synonyms:** indicate, mention
- **💡 Memory tip:** `point + out` = להצביע החוצה.

### 2003. **figure out** (v.)

- **תרגום:** להבין, לפתור

- **Example 2:** **Figure out** what happened.
- **Synonyms:** solve, understand
- **💡 Memory tip:** נפוץ מאוד בשיחה.

## 🧠 כללי זהב ל-Phrasal Verbs:

### 1. **Separable vs Inseparable**
- **Separable** (ניתן להפריד): `pick up the book` / `pick the book up`
- **Inseparable** (לא ניתן להפריד): `look after the baby` (לא `look the baby after`)

### 2. **Phrasal Verbs עם 3 חלקים**
- `come up with` - להעלות רעיון
- `put up with` - לסבול
- `look up to` - להעריץ
- `get on with` - להסתדר עם

### 3. **אותו פועל - משמעויות שונות**
- `take off`: להסיר / להמריא
- `make up`: להמציא / לפצות / להתפייס
- `break up`: להיפרד / להתפזר / לשבור
