# 🎯 קטגוריה 1: תארי פועל של דרך (20 מילים)

### 951. **clearly** (adv.)
- **Definition:** in a clear way; obviously
- **תרגום:** בבירור, באופן ברור
- **Example 1:** Please speak **clearly**.
- **Example 2:** **Clearly**, she's upset.
- **Synonyms:** obviously, evidently
- **💡 Memory tip:** מ-`clear` + `-ly`.

### 952. **obviously** (adv.)
- **Definition:** in an obvious way
- **תרגום:** באופן ברור
- **Example 1:** **Obviously**, he's angry.
- **Example 2:** She's **obviously** tired.
- **Synonyms:** clearly, evidently
- **💡 Memory tip:** משמש בתחילת משפט לחיזוק.

### 953. **probably** (adv.)
- **Definition:** most likely
- **תרגום:** כנראה
- **Example 1:** It will **probably** rain.
- **Example 2:** She's **probably** right.
- **Synonyms:** likely, presumably
- **💡 Memory tip:** 70-80% סיכוי.

### 954. **definitely** (adv.)
- **Definition:** without any doubt
- **תרגום:** ללא ספק, בהחלט
- **Example 1:** I'll **definitely** come.
- **Example 2:** **Definitely** not.
- **Synonyms:** certainly, surely
- **Antonyms:** maybe
- **💡 Memory tip:** 100% בטחון.

### 955. **certainly** (adv.)
- **Definition:** without doubt
- **תרגום:** בוודאי
- **Example 1:** I'll **certainly** help.
- **Example 2:** She's **certainly** intelligent.
- **Synonyms:** definitely, surely
- **💡 Memory tip:** פורמלי יותר מ-`definitely`.

### 956. **perhaps** (adv.)

- **Example 1:** **Perhaps** we should wait.

- **Synonyms:** maybe, possibly

# 🔗 קטגוריה 2: מילות קישור אקדמיות (15 מילים)

### 971. **therefore** (adv.)
- **Definition:** for that reason
- **תרגום:** לכן
- **Example 1:** I'm tired; **therefore**, I'll go to bed.
- **Example 2:** She studied hard; **therefore**, she passed.
- **Synonyms:** thus, hence
- **💡 Memory tip:** פורמלי מ-`so`. חשוב במבחנים!

### 972. **however** (adv.)
- **Definition:** on the other hand
- **תרגום:** עם זאת, אולם
- **Example 1:** It's cold. **However**, I love it.
- **Example 2:** **However**, there are problems.
- **Synonyms:** nevertheless, but
- **💡 Memory tip:** פורמלי מ-`but`.

### 973. **moreover** (adv.)
- **Definition:** in addition
- **תרגום:** יתר על כן
- **Example 1:** The plan is good. **Moreover**, it's cheap.
- **Example 2:** He's smart; **moreover**, he's kind.
- **Synonyms:** furthermore, also
- **💡 Memory tip:** פורמלי להוספה חזקה.

### 974. **furthermore** (adv.)
- **Definition:** in addition to what was said
- **תרגום:** בנוסף, יתר על כן
- **Example 1:** She's talented. **Furthermore**, she's hardworking.
- **Example 2:** **Furthermore**, the cost is low.
- **Synonyms:** moreover, also
- **💡 Memory tip:** פורמלי מאוד - כתיבה אקדמית.

### 975. **nevertheless** (adv.)
- **Definition:** in spite of that
- **תרגום:** אף על פי כן
- **Example 1:** It was raining. **Nevertheless**, we went out.
- **Example 2:** She's difficult; **nevertheless**, I respect her.
- **Synonyms:** however, nonetheless
- **💡 Memory tip:** `never + the + less` - ובכל זאת.

### 976. **nonetheless** (adv.)
- **Definition:** nevertheless
- **תרגום:** עם זאת
- **Example 1:** The plan failed. **Nonetheless**, we learned much.
- **Example 2:** **Nonetheless**, I appreciate the effort.
- **Synonyms:** nevertheless, however
- **💡 Memory tip:** זהה ל-`nevertheless`.

### 977. **consequently** (adv.)
- **Definition:** as a result
- **תרגום:** כתוצאה מכך
- **Example 1:** He didn't study; **consequently**, he failed.
- **Example 2:** **Consequently**, we lost money.
- **Synonyms:** therefore, thus
- **💡 Memory tip:** מ-`consequence`.

### 978. **thus** (adv.)
- **Definition:** therefore; in this way
- **תרגום:** וכך, לכן
- **Example 1:** The experiment failed; **thus**, we started over.
- **Example 2:** **Thus**, we arrived at our conclusion.
- **Synonyms:** therefore, hence
- **💡 Memory tip:** פורמלי מאוד; כתיבה אקדמית.

### 979. **hence** (adv.)
- **Definition:** for this reason
- **תרגום:** ומכאן, לכן
- **Example 1:** There's no evidence; **hence**, no conviction.
- **Example 2:** He's young; **hence**, inexperienced.
- **Synonyms:** therefore, thus
- **💡 Memory tip:** פורמלי וספרותי.

### 980. **although** (conj.) - already covered. Skipping.

### 980. **whereas** (conj.)
- **Definition:** while; in contrast
- **תרגום:** בעוד, בניגוד
- **Example 1:** He's rich, **whereas** she's poor.
- **Example 2:** I like coffee, **whereas** she prefers tea.
- **Synonyms:** while
- **💡 Memory tip:** חיבור של ניגוד פורמלי.

### 981. **unless** (conj.)
- **Definition:** except if
- **תרגום:** אלא אם כן
- **Example 1:** I won't go **unless** you come.
- **Example 2:** **Unless** it rains, we'll play.
- **Synonyms:** except if
- **💡 Memory tip:** `if not` = `unless`.

### 982. **besides** (prep./adv.)
- **Definition:** in addition to
- **תרגום:** בנוסף ל-
- **Example 1:** **Besides** English, she speaks French.
- **Example 2:** I don't want to go; **besides**, it's late.
- **Synonyms:** apart from, additionally
- **💡 Memory tip:** להבדיל מ-`beside` (ליד) - `besides` = בנוסף.

### 983. **instead** (adv.)
- **Definition:** as an alternative
- **תרגום:** במקום זאת
- **Example 1:** Let's stay home **instead**.
- **Example 2:** **Instead** of coffee, I'll have tea.
- **Synonyms:** alternatively, rather
- **💡 Memory tip:** `instead of X` = במקום X.

### 984. **according to** (prep.)
- **Definition:** as stated by
- **תרגום:** לפי, על פי
- **Example 1:** **According to** the report, sales are up.
- **Example 2:** **According to** her, it's easy.
- **Synonyms:** based on
- **💡 Memory tip:** תמיד `according to X`, לא "according X".

### 985. **whereas** - already covered. Skipping.

### 985. **despite** (prep.)
- **Definition:** in spite of
- **תרגום:** למרות
- **Example 1:** **Despite** the rain, we went out.
- **Example 2:** **Despite** her age, she runs marathons.
- **Synonyms:** in spite of
- **💡 Memory tip:** `despite` = `in spite of`. בלי `of` אחרי despite!

## 🧠 לקחים חשובים מחבילה 2:

### 1. **מילות קישור אקדמיות**
חשובות מאוד למבחן ולכתיבה:
- **סיבה:** because, since, due to
- **תוצאה:** therefore, thus, consequently, hence
- **ניגוד:** however, nevertheless, nonetheless, whereas
- **הוספה:** moreover, furthermore, in addition
- **דוגמה:** for example, for instance, such as

### 2. **הגבהה של רמת כתיבה**
החלף מילים בסיסיות בגרסה האקדמית:
- `get` → `obtain`, `acquire`
- `so` → `therefore`, `thus`
- `but` → `however`, `nevertheless`
- `about` → `regarding`, `concerning`
- `because` → `since`, `as`

### 3. **Collocations חיוניים**
- `make progress`, `make a decision`
- `play a role`, `play a part`
- `reach a conclusion`, `reach an agreement`
- `face a challenge`, `face difficulties`
- `provide evidence`, `provide information`
